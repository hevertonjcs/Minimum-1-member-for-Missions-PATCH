Crimson Desert Mod Updater - versao local sem servidor

Como usar:

1. Extraia esta pasta em qualquer lugar do Windows.
2. Dê dois cliques em INICIAR_LOCAL.bat ou abra index.html.
3. Faça upload do JSON antigo, analise, atualize e baixe o resultado.

Como atualizar os offsets:

Nesta versao local, os offsets ficam embutidos no arquivo local-data.js.
Para publicar uma nova versao local, gere novamente o pacote com o local-data.js atualizado.

Estrutura esperada:

index.html
app.js
local-data.js
INICIAR_LOCAL.bat

Observacao:

Esta versao nao precisa de PowerShell, Node, Python, Supabase ou internet.
